# Mode-Explorer for TidalCycles
本アプリケーションは、TidalCyclesでの使用を前提としたスケールの視覚化、比較、および発音確認を行うためのウェブアプリケーションです。
動作環境はデスクトップ版Chromeのみで確認しています。スマートフォン表示には対応していません。

音程の確認用なので、コードスニペットのような機能は実装されていません。
スケール名の規則さえ分かれば、DAWでの作曲にも少しは役に立つかもしれません。

## ⚠️ 前提条件および注意事項
本ツールをTidalCyclesの制作ワークフローで活用するためには、以下の前提条件を理解しておく必要があります。

### 独自スケール名に準拠
本アプリに登録されているスケール名は、TidalCyclesのデフォルト名ではなく、KURAYAMIが使用している独自の命名規則に基づくモード定義コードおよび、TidalCycles標準のスケール定義を基準としています。命名規則は下記の通りです。
- [チャーチモード7種の名称]
- [そこからシフトする方向:n(natural),f(flat),s(shape)]
- [シフトする音階数]

（例: doriann7, locrianf4）

### BootTidal.hsの更新
本アプリ内のスケール名をTidalCycles上で実行するには、事前にBootTidal.hs 内へ以下のモード定義（カスタムスケール群）を追記し、TidalCycles内に読み込ませておく必要があります。
```haskell
scale = getScale (scaleTable ++ [("doriann7",[0,2,3,5,7,9,11]),("phrygiann6",[0,1,3,5,7,9,10]),("lydians5",[0,2,4,6,8,9,11]),("lydianf7",[0,2,4,6,7,9,10]),("mixolydianf6",[0,2,4,5,7,8,10]),("locriann2",[0,2,3,5,6,8,10]),("locrianf4",[0,1,3,4,6,8,10]),("aeoliann7",[0,2,3,5,7,8,11]),("locriann6",[0,1,3,5,6,9,10]),("ionians5",[0,2,4,5,8,9,11]),("dorians4",[0,2,3,6,7,9,10]),("phrygiann3",[0,1,4,5,7,8,10]),("lydians2",[0,3,4,6,7,9,11]),("locrianf4f7",[0,1,3,4,6,8,9]),("ionianf6",[0,2,4,5,7,8,11]),("dorianf5",[0,2,3,5,6,9,10]),("phrygianf4",[0,1,3,4,7,8,10]),("lydianf3",[0,2,3,6,7,9,11]),("mixolydianf2",[0,1,4,5,7,9,10]),("lydians2s5",[0,3,4,6,8,9,11]),("locrianf7",[0,1,3,5,6,8,9])])
```

### 度数とインターバルの表記差異
一般的な音楽理論ではルート音（ユニゾン）を「1度」として序数で数えますが、TidalCyclesのコード内における配列（[0, 2, 4...] など）は「0起点」が採用されています。本アプリではそちらに準拠し
、アプリ内のノード番号「0」がルート音を指します。

### スケール説明に関する注意
アプリ内に表示される各スケールの説明文は、AIを利用して作成しています。そのため個人の主観的な印象や音楽的文脈と一致する保証はありません。あくまでインスピレーションの補助としてご活用ください。

## 画面構成と機能一覧
1. **Scale Visualizer**（左パネル：円形ビジュアライザ）
  - 選択したスケールの構成音を円形に視覚化し、マウスクリックで直接発音させることができます。
    - 同心円3オクターブ表示:
      - 中央のリング: 基準オクターブ
      - 内側のリング: +1オクターブ
      - 外側のリング: -1オクターブ
    - カラーコーディング:
      - 水色: 現在選択中のスケール構成音。
      - 緑色（追加） / 赤色（消滅）: 右下パネルで他のスケールにマウスホバーした際、現在のスケールとの「差分」を動的に色分け表示します。
      - オレンジ色（Subset）: 右パネルで「Included Subsets」内のタグボタンをオンにした際、そのサブセット（5音/6音）に該当する音のみがハイライトされます。
    - 表示モード切替（View）: 半音階順（Chromatic）と五度圏（Circle of Fifths）の並び順をトグルボタンで切り替えられます。

2. **コントロールパネル**（右パネル上部）
- スケールの選択と、オーディオ・MIDI機能の制御を行います。
  - **Scale Selection** : メインとなる7音モード、または特殊スケールを選択します。主表記はTidalcycles内でのスケール名で、カッコ内は通称や一般的な名称です。
  - **Root Note** : ルート音（C〜B）を指定します。
  - **Octave Shift** : アプリ全体の発音オクターブを-2〜+2の範囲で一括シフトします。※上下オクターブの演奏時にMIDIノートの制限（0〜127）を超えた場合は発音されません。
  - **Master Vol** : 内蔵シンセサイザーのマスター音量を調整します。
  - **MIDI Out** : 接続されている外部MIDIデバイスを選択します。内蔵シンセサイザーと同時にMIDI Note On/Off信号が送信されます。内蔵シンセの音が不要の場合は、マスターボリュームを０にしてください。※起動時にブラウザにMIDI機能への許可を与えなかった場合は、機能しません。
  - **HOLD** : オンにすると、発音したノートが減衰せずに鳴り続けます。同じノートを再度発音させるか、HOLDをオフにすることで停止します。
  - **PLAY SCALE** : 選択中のスケールの構成音を、低い音から順番に自動演奏します。

3. **インフォメーション ＆ 関係性リスト**（右パネル下部）
選択中のスケールに関する情報と、モーダルインターチェンジの候補を提示します。
  - 基本情報: スケール名、モードグループ、対応する和音名、傾向、および特徴の説明文を表示します。
  - Tidal Default Names / Aliases: TidalCyclesのデフォルトで用意されている同音異名のスケールが存在する場合、折りたたみメニュー内に名前が表示されます。
  - Included Subsets: 選択中のスケールに内包されている5音・6音スケールの名称が表示されます。クリックするとビジュアライザ上で該当音がオレンジ色にハイライトされます。マウスホバーでサブセットの特徴がツールチップ表示されます。
  - Modal Interchange / Modulations: 構成音の差分に基づき、移行先候補を以下の3カテゴリに分類してリストアップします。
    - Very Close: 1〜2音の変化で移行できるスケール。
    - Moderate Shift: 3〜4音の変化を伴うスケール。
    - Relative Modes: 構成音が完全に一致し、ルート音だけが異なるスケール（平行調）。リストにはルート音のシフト量が表示されます。

## キーボード・ショートカット
PCのキーボードを使用して、ルート変更やスケールクオンタイズされた音での演奏が可能です。
  - ← / → (矢印キー): ルート音（Root Note）を半音単位で上下に変更します。
  - スケール演奏: 選択中のスケール（またはハイライト中のサブセット）の構成音に自動的にマッピングされます。
    - Z, X, C, V, B, N, M, , , ., / : 基準より -1オクターブ のスケール音
    - A, S, D, F, G, H, J, K, L, ;, ' : 基準オクターブのスケール音
    - Q, W, E, R, T, Y, U, I, O, P, [, ] : 基準より +1オクターブ のスケール音
